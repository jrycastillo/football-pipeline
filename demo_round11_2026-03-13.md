## Root Cause Analysis

**Why tackles/shots/dribbles exploded on long videos:**
- The pipeline detects events by tracking ball ownership changes between players
- When Player A loses the ball to Player B, it counts as a tackle or other event
- On long videos (482K frames), rapid ownership oscillations generated thousands of false events
- Previous cooldown timers were too short to filter these out

**Why passes were NOT debounced (correction from earlier analysis):**
- V1/V2/V3 pass counts in Round 10 (96, 60, 283) are already at realistic levels
- V4's pass inflation (1,582) is caused by team imbalance (30 White vs 7 Red), not rapid counting
- A pass debounce would have over-corrected V1/V2/V3, making already-normal counts too low
- V4's pass problem will be fixed by improving team balance, not event debouncing

**Why distance was near-zero on Video 2:**
- `finalize_bindings` mapped multiple tracking fragments to the same jersey number
- When two fragments overlap in time, two bounding boxes with the same player ID appear in one frame
- The distance calculator alternated between two physical locations each frame
- Every jump exceeded the speed limit (1.44m/frame) and was discarded
- Result: thousands of frames processed, near-zero distance accumulated

---

## Four Fixes Applied

**1. Tackle Cooldown Increase**
- Before: 5-second cooldown per tackler
- After: 15-second cooldown per tackler
- A real tackle happens once every few minutes, not every 5 seconds
- Reduces false tackle counting from ownership noise

**2. Shot Debounce Increase**
- Before: 1-second global cooldown
- After: 5-second global cooldown
- Ball bounces, deflections, and rebounds no longer count as separate shots
- Matches real-world shot frequency

**3. Dribble Cooldown Increase**
- Before: 1-second cooldown per player
- After: 3-second cooldown per player
- Prevents the same dribble attempt from being counted multiple times

**4. Distance Deduplication**
- Before: All bounding boxes processed, including duplicates
- After: Only the first box per player ID per frame is processed
- Eliminates the position oscillation that caused near-zero distances
